# Проект 0. Угадай число менее чем за 20 попыток
## Оглавление
### 1. Описание проекта
Угадываем случайное число заданное компьютером в диапазоне от 1 до 100 менее чем за 20 попыток.
### 2. Какой кейс решаем
Реализуем программу на языке Python, которая угадывает число от 1 до 100 менее чем за 20 попыток (в нашем случае угадываем за 4-6 попыток). 
### 3. Этапы работы над проектом
Реализована функция random_predict #Для угадывания числа с минимизацией количества попыток
1) Вводим переменные для счетчика, максимально и минимально возможных чисел.
2) Задаем условия проверки (больше или меньше наше число загаданного).
3) В зависимости от условия изменяем максимально либо минимально возможное число (уменьшаем диапазон допустимых значений), а само число проверяем по середине нового числового диапазона (для минимизации количества попыток).
### 4. Результат
Результат работы проекта "Угодай число":
1) 	Программа находит число меньше чем за 20 попыток. Если данное условие не выполняется, выставляется 0 баллов за это и все остальные условия.
